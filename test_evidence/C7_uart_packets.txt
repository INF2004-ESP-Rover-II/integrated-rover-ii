C7: Sensor Pico to Robo Pico UART packets (FR-13)
Source: Robo Pico USB serial monitor, real rover. [STATS] counts every UART packet since boot: total, valid (sync and checksum OK) and errors.
Requirement: the Robo Pico decodes every Sensor Pico packet with 0 errors.

Fix: the Robo Pico expected a 67-byte packet (old layout with magnetometer fields) while the Sensor Pico sent 59 bytes. After matching the 59-byte layout, errors dropped to 0. (Before the fix the error count reached 1232; that figure was noted during testing, no log was kept.)

Result: 0 errors in every session after the fix, up to 2079 consecutive valid packets.
